# Jiggy

> _Get Jiggy with it!_

Jiggy is a highly work in progress reimplementation/decompilation of RAD Game Tools's Iggy library.
Jiggy does not aim to be 1 to 1 with the original Iggy library, but rather to make a modern alternative to the original, with backwards compatibility!
[!IMPORTANT]

> This is in EXTREMELY **EXTREMELY** early development. While it may compile, it's not going to work for quite a while.
